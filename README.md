# Business Data Analysis and Reporting Project

## Project
Retail Sales Performance Analysis

## Dataset
A simulated retail sales dataset created for this learning project. It is not actual company data. It includes order date, region, channel, product category, product, units sold, price, revenue, cost, and profit. Intentional missing values and a duplicate row are included to practise data cleaning.

## Files
- `business_sales_analysis.ipynb`: complete analysis notebook
- `retail_sales_dataset.csv`: practice dataset
- `report.docx`: detailed business report
- `requirements.txt`: required Python packages
- PNG files: charts used in the report

## Setup
1. Install Python 3.
2. Open a terminal in this folder.
3. Run `python -m pip install -r requirements.txt`.
4. Run `jupyter notebook`.
5. Open `business_sales_analysis.ipynb` and run all cells.

## Business analysis
The notebook checks data quality, cleans missing and duplicate records, calculates KPIs, analyzes categories, regions and channels, visualizes monthly revenue, and produces business recommendations.
